# STR GARAGE WEBSITE PROJECT REPORT

## 1. Business Name and Introduction

**STR Garage – More Than Just a Garage.**

STR Garage is a fictional motorcycle repair and maintenance business created as part of an educational website development project. The website is designed to introduce the workshop's profile, maintenance and repair services, price lists, gallery, and contact information. Through this website, visitors can easily explore the services offered by STR Garage in a modern, organized, and user-friendly way.

## 4. How to Run the Website

Follow these steps to run the website:

1. Make sure the STR Garage project folder is available on your computer.
2. Open the project folder using Visual Studio Code.
3. Make sure all folders and supporting files, such as assets, pages, and styles, are organized correctly.
4. Open the `index.html` file.
5. Run the website using the Live Server extension in Visual Studio Code.
6. Once the browser opens, the STR Garage homepage will appear.
7. Visitors can use the navigation bar to access the About Us, Our Services, Price List, Gallery, and Contact Us pages.

## 7. Development Process and Challenges

During the development of the STR Garage website, the group encountered several challenges. The following are some of the problems and how they were solved:

1. **Branch Name Errors**

    One of the challenges was frequently making mistakes when naming branches, such as using incorrect capital letters or making typos. These mistakes required the group to correct each branch name individually through the terminal.

2. **Conflicts When Pushing Changes**

    Another challenge occurred when a group member pushed changes before pulling the latest updates from another member. This caused conflicts between the changes. The group solved this by making sure to pull the latest updates before pushing new changes.

3. **Inconsistent Website Information**
   Some information on the website was inconsistent because of a lack of communication between group members. To solve this, the group reviewed the website content to make sure the information remained consistent across all pages.

4. **Image Size and File Naming Issues**

    One of the challenges was that the images used on the website had to be a maximum of 300 KB. However, the group did not pay enough attention to this requirement at first, so many images had to be compressed or replaced. In addition, some image files had unclear names, such as "garage 1" and "garage 2". These file names had to be corrected and organized to make them easier to identify and manage.
